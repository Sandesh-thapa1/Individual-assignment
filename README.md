# Student Eats Finland

A web application for finding student restaurants in Finland and viewing their daily and weekly menus.

## Features

- Restaurant search and city/provider filters
- Daily and weekly menus with date selection
- English and Finnish menu options
- Registration, login and profile editing
- Profile picture upload and one saved favourite per account
- Restaurant map and nearest-restaurant highlighting
- Responsive layout

## Technologies

HTML, CSS, vanilla JavaScript, Metropolia Restaurant API and OpenStreetMap tiles.

## Files

- `index.html` — page structure
- `style.css` — styling
- `main.js` — menus, filters and accounts
- `map.js` — map and markers
