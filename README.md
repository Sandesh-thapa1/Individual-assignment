# Student Eats Finland

A web application for finding student restaurants in Finland and viewing their daily and weekly menus.

## Live Website

[Open Student Eats Finland](https://users.metropolia.fi/~sandest/student-eats/)

## Features

- Restaurant search and city/provider filters
- Daily and weekly menus with menu-day selection
- English and Finnish menu options
- Registration, automatic login and profile editing
- Profile picture upload and one saved favourite per account
- Restaurant map and nearest-restaurant highlighting
- Responsive layout

## Technologies

HTML, CSS, vanilla JavaScript, Metropolia Restaurant API and OpenStreetMap tiles.

## Files

- `index.html` — page structure
- `style.css` — styling and responsive layout
- `map.js` — map and markers
- `js/main.js` — application startup
- `js/api.js` — API requests
- `js/utils.js` — shared helper functions
- `js/restaurants.js` — restaurant list, filters and favourites
- `js/menus.js` — daily/weekly menus and prices
- `js/account.js` — registration, login and profile management
